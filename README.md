# Java Stream API Practice

A collection of Java 8+ Stream API programs and coding exercises designed to build a strong understanding of functional-style programming, collections processing, and modern Java techniques.

This repository contains practical examples and problem-solving exercises using the Java Stream API, with each problem organized into a separate package for better maintainability and readability.

---

## 📌 About the Repository

The purpose of this repository is to practice and understand how the Java Stream API can be used to process collections and perform operations such as filtering, mapping, sorting, aggregation, grouping, and collecting.

The programs are implemented using Java 8+ features and follow standard Java naming and package conventions.

---

## 🛠️ Technologies Used

- **Java 8+**
- **Stream API**
- **Lambda Expressions**
- **Functional Interfaces**
- **Method References**
- **Collectors**
- **Collections Framework**
- **Eclipse IDE**
- **Git & GitHub**
